---
title: CLI credentials
description: Configure the server endpoint and Basic Auth credentials used by the Enstore CLI.
---

## Login

```bash
enstore login <endpoint> <username>
```

By default, credentials are saved to `~/.enstore/credentials.json`:

```json
{
  "endpoint": "https://storage.example.com",
  "username": "alice",
  "encryptedPassword": "base64encodedvalue"
}
```

<Warning>
  `encryptedPassword` is Base64-encoded, not encrypted. Restrict access to the credentials file and never commit it.
</Warning>

## Custom credentials file

Use the global `-c` option before the command:

```bash
enstore -c ./staging-credentials.json login https://staging.example.com alice
enstore -c ./staging-credentials.json ls /
```

## Environment variables

Environment variables override values loaded from a file:

```bash
export ENSTORE_ENDPOINT='https://storage.example.com'
export ENSTORE_USERNAME='alice'
export ENSTORE_PASSWORD='secret'
enstore ls /
```

The client needs all three resolved values before it can run protected commands.
