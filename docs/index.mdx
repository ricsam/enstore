Enstore is a file management toolkit for storing and accessing files over HTTP. It combines a self-hosted server, role-based access control, a command-line client, and a familiar Node.js filesystem interface.

## What Enstore provides

- **File operations** — list directories, read files, create directories, and upload content.
- **HTTP Basic authentication** — authenticate every protected request with a username and password.
- **Role-based access control** — assign `read`, `write`, and `manageUsers` permissions through customizable roles.
- **Multiple deployment modes** — use a standalone command, Express middleware, or Docker.
- **Multiple clients** — use the `enstore` CLI, call the HTTP API, or install `@enstore/fs`.

## Packages

| Package | Purpose |
| --- | --- |
| `@enstore/server` | Express middleware and the `enstore-server` executable |
| `@enstore/cli` | The `enstore` command for remote file and access management |
| `@enstore/fs` | Node.js-style promise and stream APIs for remote files |

<Note>
  Enstore stores uploaded content on disk and stores users and roles in a JSON file. Back up both locations when operating a production server.
</Note>
